# Puzzle Break

An iPhone-first offline Progressive Web App with three touch puzzle modes: Zip, Patches, and Queens.

## Deploy

Upload this folder to Vercel or Netlify. HTTPS is required for service-worker installation on iPhone Safari.

After deploying, open the HTTPS URL on iPhone, tap Share, then Add to Home Screen. The app caches its HTML, CSS, JavaScript, manifest, icons, and sounds for offline play after the first load.
